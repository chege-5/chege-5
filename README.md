## VulNexus

### AI-assisted hybrid security auditing platform

VulNexus combines security scanning, vulnerability intelligence, reporting, and AI-assisted remediation in one full-stack platform.

**Highlights**

- URL, source code, ZIP, and GitHub repository scanning
- Secrets, dependencies, TLS, headers, DNS, and compliance checks
- CVE/CWE-aware findings and threat-intelligence enrichment
- RBAC, MFA, OAuth, email verification, and secure reports
- React, FastAPI, Celery, Redis, and PostgreSQL architecture
